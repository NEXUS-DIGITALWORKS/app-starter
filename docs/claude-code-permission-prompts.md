# Claude Code 権限確認ダイアログ 英語→日本語対訳表

Claude Code(AIコーディングツール)がツール実行前に表示する権限確認ダイアログの、カテゴリ別英語タイトルパターンと日本語訳の対応表。

| カテゴリ | 英語タイトル(典型パターン) | 日本語 |
|---|---|---|
| Bashコマンド実行 | "Allow this bash command?" | このbashコマンドを許可しますか? |
| ファイル読み取り | "Allow reading from [path]?" / "Allow Claude to read [file]?" | [パス]からの読み取りを許可しますか? |
| ファイル編集(既存) | "Allow edit to [file]?" / "Allow Claude to edit [file]?" | [ファイル]の編集を許可しますか? |
| ファイル新規作成 | "Allow file creation at [path]?" / "Allow Claude to create [file]?" | [パス]でのファイル作成を許可しますか? |
| ファイル削除 | "Allow deleting [file]?" | [ファイル]の削除を許可しますか? |
| WebFetch(URL取得) | "Allow fetching from [domain]?" | [ドメイン]からの取得を許可しますか? |
| WebSearch | "Allow Claude to search the web?" | Webでの検索を許可しますか? |
| MCPツール呼び出し | "Allow [server] to use [tool]?" / "Allow Claude to use [tool]?" | [連携先]の[ツール]利用を許可しますか? |
| NotebookEdit | "Allow editing notebook [file]?" | ノートブック[ファイル]の編集を許可しますか? |

共通して文末は "Do you want to proceed?" が添えられることが多い。
